# LATIN — Pour la vie

Application React de découverte des treize citations latines, du film d’introduction et de la présence du latin au quotidien.

## Fonctionnalités

- **Exploration des citations** : 13 citations numérotées en chiffres romains (I à XIII), classées par thèmes (*Vivre*, *Oser*, *Penser*) avec recherche insensible aux accents.
- **Lecteur de citation** : Modal immersif affichant le texte latin, la traduction française, l’attribution d’auteur, la copie vers le presse-papiers et la navigation séquentielle.
- **Film d'introduction (1 min 45)** : Lecteur vidéo avec barre de progression, réglage de vitesse (0,75× à 1,5×), sélection directe par chapitres et raccourcis clavier.
- **Le latin au quotidien** : 8 découvertes modernes (Audi, Expecto Patronum, Acer, etc., ASICS, locutions courantes).
- **Crédits et sources** : Inventaire documenté des ressources visuelles et musicales (NASA, ESO, MDN, CC0).
- **Statistiques** : Tableau de bord des visites uniques.

## Développement

Projet propulsé par React, TypeScript et Vite :

```sh
npm install
npm run dev
```

Le serveur de développement démarre sur `http://localhost:3000`.
